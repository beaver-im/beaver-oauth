# 8.2 版权头脚本

[返回本章](README.md) · [全书目录](../README.md)

## 命令与作用域

`npm run add-copyright-header` 执行 `node scripts/add-copyright-header.mjs`。
脚本递归扫描 `src/`，处理 `.ts/.vue/.js/.mjs/.cjs`；跳过 node_modules、dist、.git。
它不处理 `types/auto`、`static`、`public` 或 `docs`。

这是**会写文件**的命令，不是检查器。执行前保存/检查 diff，执行后逐文件确认没有误替换业务注释。

## 注入规则

- TS/JS 使用 `/** ... */`，Vue 使用 `<!-- ... -->`。
- 保留 shebang 在最前，版权头放在其后。
- 若文件前 1200 字符已含 `beaver-oauth-header-v1`，直接跳过，不检查内容是否完整。
- 否则识别已有 Beaver/MIT 头并替换，再写入当前 `beaver-oauth-header-v1` 模板。
- 模板包含 Copyright、SPDX、Project、仓库 URL 与中英双语声明。

## 风险与边界

`hasCurrentVersion` 只检查标记存在，不验证版权内容；`isOurHeader` 会识别含 MIT 或 Beaver Copyright 的头部。
因此不要把该脚本用于清理第三方文件、批量格式化或删除历史注释。
新增文件优先按同目录相邻文件复制头；只有需要批量补齐时运行脚本。

根 `LICENSE` 与 `LEGAL.md` 是授权事实源，脚本不会修改它们，也不应被改成修改许可的工具。
若模板、年份、项目名或作用域变化，需要同步脚本、源码、本页、AGENTS 与目录地图。
