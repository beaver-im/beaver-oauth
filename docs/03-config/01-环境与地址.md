# 3.1 环境与地址

[返回本章](README.md) · [全书目录](../README.md)

## 环境文件

只有 `.env.dev`、`.env.test`、`.env.prod`，不存在 `.env.example`、`.env.development`、`.env.production`。

| mode | `VITE_API_BASE` 当前值 |
|---|---|
| dev | `http://127.0.0.1:20800/beaver-open` |
| test | `https://server-test.wsrh8888.com/beaver` |
| prod | `https://server.wsrh8888.com/beaver` |

`config.baseAPI` 是唯一请求基址。API 文件在其后拼 `/api/open/oauth_public/v1/...`，
不要在页面或 SDK props 中另写域名。

## 必填校验

`requireEnv` 对 undefined、空串和纯空白抛 `请配置 VITE_API_BASE`，并 trim 非空值。
没有本地默认值或生产兜底；配置缺失应在启动阶段暴露，而不是静默请求错误地址。

所有 `VITE_*` 值都会暴露给浏览器，只能放公开信息。`appSecret`、token、签名密钥不得进入任何环境文件。

## 环境名不一致

`.env.*` 定义 `VITE_API_ENV=dev/test/prod`；`env.ts` 与 `vite.config.ts` 读取 `VITE_APP_ENV`。
因此 `config.env` 和 `__APP_ENV__` 当前为 undefined，`baseAPI` 仍正常。
修复键名需要同时改三份 env、源码、Vite define、文档与部署注入，不能只改一端。

相关决策：[ADR 0002](../10-decisions/0002-环境配置单一来源.md)。
