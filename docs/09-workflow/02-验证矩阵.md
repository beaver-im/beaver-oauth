## 命令

| 范围 | 命令 | 副作用/边界 |
|---|---|---|
| 文档登记/链接/章序 | `node scripts/check-knowledge.mjs` | 只读，不验证语义或代码 |
| 开发服务 | `npm run dev` | 启动服务，写 Vite 缓存/生成声明 |
| 测试构建 | `npm run build_test` | 类型检查 + 写 dist |
| 生产构建 | `npm run build_prod` | 类型检查 + 写 dist |
| Lint | `npm run lint` | `eslint . --fix`，修改文件 |
| 版权头 | `npm run add-copyright-header` | 扫描并重写 src 文件头 |

没有 `test` 脚本，没有单元/集成测试，不宣称覆盖率。需要额外静态检查时记录实际工具与命令。

## 按改动验证

| 改动 | 最低验证 |
|---|---|
| 纯文档 | 文档校验 + 链接/路径抽查 |
| 页面 | 构建 + 正常/缺参/业务失败/网络失败/移动端 |
| API/DTO | 构建 + 服务端契约对照 + HTTP/业务失败 |
| 环境 | 目标 mode 构建 + 产物基址检查 + 部署联调 |
| 路由 | 直接访问、刷新、前进/后退、静态回退 |
| SDK | 浏览器真实注册、登录、授权、回调白名单 |
| 扫码 | scene 查询、过期/取消/已确认、App 内确认 |
| 版权头 | 执行后 git diff 抽查，确认只改头部 |

## 真机/服务前置

- 目标环境 `VITE_API_BASE` 与 CORS 可用。
- SDK 包版本与公开端点匹配。
- App 扫码、确认、取消与二维码过期状态可构造。
- 静态托管支持 HTTPS 与 History 回退。

文档脚本通过不等于构建、测试、安全审计或端到端授权通过。最终报告分开写“已执行”和“未执行”。
