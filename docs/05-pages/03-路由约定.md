# 5.3 路由约定

[返回本章](README.md) · [全书目录](../README.md)

## 路由表

| 路径 | name | 行为 |
|---|---|---|
| `/scan` | `Scan` | 懒加载扫码引导页 |
| `/auth` | `Auth` | 懒加载 SDK 授权页 |
| `/` | 无 | 重定向 `/auth` |

使用 `createWebHistory()`，没有 Hash，也没有 `beforeEach` 等守卫。
没有 404 路由、权限路由、布局路由或嵌套路由；新增复杂导航前先确认是否超出公开页边界。

## 参数与路由

页面直接从 `window.location.search` 读 query，不定义 route props 或 query schema。
同一路由内 query 变化不会自动重新执行 setup/onMounted；若 SDK 需要响应参数变化，要显式 watch 或重新导航，
不能假设 Vue Router 会重建页面。

## 静态部署

`base: './'` 让构建资源适合子目录，但 History 深链仍依赖服务器回退。
部署 `/scan?sceneId=...` 后直接刷新，服务器必须返回 `index.html`，否则会 404。
CDN/对象存储的规则因平台而异，本仓没有部署脚本，不虚构 Nginx 配置。

## 新增路由检查

- name 唯一，组件懒加载路径存在；
- 更新 `docs/README.md` 与相关页面说明；
- 验证直接访问、刷新、返回/前进与 query 变化；
- 确认不把敏感 code/token 放进可分享 URL；
- 不需要鉴权时不要添加伪装成安全的客户端守卫。
