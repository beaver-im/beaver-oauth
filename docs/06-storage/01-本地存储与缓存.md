# 6.1 本地存储与缓存

[返回本章](README.md) · [全书目录](../README.md)

## 当前实现

检索 `src/` 没有 localStorage、sessionStorage、IndexedDB、Cookie 或 Cache Storage 的业务读写。
授权页与扫码页只使用 Vue `ref` 保存当前页面状态；刷新后重新读取 URL 与接口。
`checkQrCodeStatusApi` 未接入，因此也没有扫码状态缓存或授权 code 缓存。

`@beaver-im/js-sdk` 是外部依赖，可能维护自己的登录态；其内部存储不属于本仓，
不要根据本仓“无持久化”推断 SDK 不保存任何状态，也不要把 SDK 存储复制到业务代码。

## 敏感数据

URL 中的 `oauthId`、`redirectUri`、`sceneId` 可能进入浏览器历史、Referer 或监控系统。
不要把 `code`、token、appSecret 追加到当前 URL，也不要写入 console、localStorage 或分析事件。
需要排查时只记录必要的 sceneId/oauthId，并确认日志服务的数据保留与访问控制。

## 新增存储前

先回答：数据是否跨页面/刷新必需、是否敏感、生命周期多长、用户如何清除、SDK 是否已提供。
公开授权页默认不缓存授权结果；若引入存储，需要更新本章、安全说明和验证矩阵，并避免长期 token 落地。

## 缓存与请求

axios 当前没有缓存、重试或离线队列。两个 GET 都是实时查询，不能在页面中自行缓存“confirmed”结果，
否则可能接受已取消/过期的授权。轮询与状态消费必须由明确流程实现，不能靠浏览器缓存。
