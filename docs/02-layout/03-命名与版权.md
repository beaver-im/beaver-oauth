# 2.3 命名与版权

[返回本章](README.md) · [全书目录](../README.md)

## 命名

| 对象 | 约定 |
|---|---|
| API 函数 | `<动作><对象>Api`，如 `getQrCodeSceneApi` |
| DTO | `I<动作><对象>Req/Res` |
| HTTP 方法 | `ajax<T>(AxiosRequestConfig)` |
| 配置 | `config.baseAPI`，环境键使用 `VITE_` 前缀 |
| 页面目录 | `pages/<语义>/index.vue` |
| 路由 | 小写 `/auth`、`/scan`，name 使用 PascalCase |
| 状态值 | 与服务端一致：waiting/scanned/confirmed/cancelled/expired |

字段名保持服务端 JSON 的 camelCase，如 `sceneId`、`oauthId`、`redirectUri`、`expireIn`。
Go 结构体字段可能写成 `SceneID`，但 JSON tag 是 `sceneId`，前端不要改成 `sceneID`。

## 代码风格

`.editorconfig` 使用 UTF-8、2 空格、LF。ESLint 配置为双引号、无分号、2 空格，
Vue 块顺序规则写成 script/template/style，但现有页面实际是 template/script/style；不要为迎合规则批量重排无关文件。
`npm run lint` 会 `--fix`，执行后必须检查 diff。

## 版权头

`src/` 下 `.ts/.vue/.js/.mjs/.cjs` 使用 `beaver-oauth-header-v1`，包含 MIT SPDX 与中英声明。
新增文件可运行 `npm run add-copyright-header`，但该命令会扫描并重写 src，不是单文件工具。
已有文件不得删除或替换版权头，也不得修改根 `LICENSE`。

`types/auto/auto-imports.d.ts` 是生成物，不补业务版权头；`static/` 与 `docs/` 不属于该脚本作用域。
