## 项目定位

仓库目录与版权头 `PROJECT` 都是 `beaver-oauth`，`package.json.name` 是 `beaver-open`，版本 `2.0.2`。
三者不要混用，也不要为了“统一命名”修改包名。`VERSION` 与 `package.json.version` 当前一致。

这是一个 Vue 3 公开授权页，不是 OAuth 服务端，也不是独立账号系统。
登录 UI 与授权交互由 `@beaver-im/js-sdk` 提供；本仓负责入口参数、页面引导和两个公开查询接口。

## 工具链

| 技术 | 当前用途 |
|---|---|
| Vue 3 / TypeScript 5.8 | 页面、严格类型检查 |
| Vite 7 | dev/serve/build 与 `.env.<mode>` 加载 |
| Vue Router 4 | `/auth` 与 `/scan` 的 History 路由 |
| Axios 1.10 | 唯一 HTTP 客户端 |
| `@beaver-im/js-sdk` | 授权页注册 SDK 与 `<beaver-login>` |
| Element Plus | 已安装并加载全局类型，但当前未注册完整组件库 |
| unplugin-auto-import | 生成 vue/vue-router/pinia 全局声明 |

AutoImport 配置包含 pinia，但依赖中没有 pinia，`main.ts` 也没有 `createPinia`。
`unplugin-vue-components` 只在 devDependencies 中，Vite 未启用，不能声称当前会自动注册本地组件。

## 脚本事实

`package.json` 只有 dev、serve_prod、serve_test、build_prod、build_test、lint、prepare、add-copyright-header 等脚本。
没有 `test`、`typecheck`、`build_dev`。生产/测试构建先执行 `vue-tsc -b`，再执行 Vite build。

`npm install` 会触发 `prepare: husky`；`npm run lint` 是 `eslint . --fix`，会修改文件。
执行写操作命令前先检查工作树，不把它们当只读检查。

事实源：[package.json](../../package.json)、[vite.config.ts](../../vite.config.ts)、
[tsconfig.app.json](../../tsconfig.app.json)、[main.ts](../../src/main.ts)。
