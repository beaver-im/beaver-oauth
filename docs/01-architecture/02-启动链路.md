# 1.2 启动链路

[返回本章](README.md) · [全书目录](../README.md)

## 浏览器入口

1. `index.html` 提供 `#app` 与 `/src/main.ts`。
2. `src/main.ts` 创建 Vue 应用，只注册 router，然后挂载；没有 Pinia、Element Plus 或全局布局。
3. `src/App.vue` 只有 `<router-view />` 与基础样式。
4. router 按 `/auth`、`/scan` 懒加载页面，`/` 重定向 `/auth`。

`createWebHistory()` 使用真实路径。部署到静态站点时，深层路径刷新需要服务器将未知前端路由回退到 `index.html`；
本仓没有服务器回退配置，不能只验证首页就宣称深链可用。

## 配置求值

`src/config/env.ts` 在模块加载时立即执行 `requireEnv(VITE_API_BASE)`。
缺失或空白会抛 `请配置 VITE_API_BASE`，没有默认域名。由于 API 模块依赖 config，
错误配置会在页面正常渲染前阻断依赖链。

`config.env` 读取 `VITE_APP_ENV`，Vite 的 `define.__APP_ENV__` 也读取同名键；
三份 `.env.*` 当前只定义 `VITE_API_ENV`，所以环境展示值实际为 undefined。基址不受该键影响。

## 构建时插件

Vite 使用 `vue()` 与 AutoImport；AutoImport 写 `types/auto/auto-imports.d.ts`。
该声明文件是生成物，不手改。它包含 pinia 声明不代表应用已安装或使用 Pinia。

## 页面生命周期

授权页在 setup 读取 query，在 `onMounted` 调 `BeaverSDK.register()` 并检查 `oauthId`。
扫码页在 `onMounted` 读取 `sceneId` 并异步查询 scene。
没有全局路由守卫、全局请求错误处理或统一 loading 框架；页面各自处理少量状态。
